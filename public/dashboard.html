API Docs

Integrasikan ke ZaeinStore atau sistem lainnya

Base URL server kamu:
https://your-railway-url.railway.app
Authentication (header untuk semua request):
X-Api-Key: YOUR_API_SECRET_KEY
POST /api/qris/generate

Generate QRIS dinamis untuk satu transaksi

// Request body { "amount": 50000, "buyer_email": "buyer@email.com", // opsional "product_id": "film-001", // opsional "metadata": {} // opsional } // Response { "success": true, "data": { "transaction_id": "xxx-xxx-xxx", "order_id": "ZP-1234567890-ABC", "amount": 50000, "status": "pending", "qr_url": "https://...", "expiry_time": "2024-03-30 10:30:00" } }
POST /api/qris/status
// Request { "transaction_id": "xxx-xxx-xxx" } // Response { "success": true, "data": { "status": "settlement", ... } }
GET /api/qris/poll/:transactionId

Untuk polling status dari frontend (countdown timer)

POST /webhook/gopay

Daftarkan URL ini ke GoPay sebagai callback. Otomatis forward ke ZaeinStore Worker.

Contoh integrasi di Cloudflare Worker ZaeinStore sudah tersedia di docs/integration.md

Pengaturan

Environment Variables

Semua konfigurasi diatur via file .env. Lihat .env.example untuk panduan lengkap.

PORT=3000 API_SECRET_KEY=your_secret GOPAY_PHONE=0812xxx SUPABASE_URL=https://xxx.supabase.co SUPABASE_KEY=eyJ... ZAEINSTORE_WEBHOOK_URL=https://api-pay.semuapro.store/gopay-callback DASHBOARD_USERNAME=admin DASHBOARD_PASSWORD=yourpass

Restart server setelah mengubah .env
